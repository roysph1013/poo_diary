# 嗯嗯日記

記錄每天的嗯嗯形態、飲食、睡眠與心情，看看腸道狀況是不是受到吃的東西、心情或作息影響。

## 功能

- **嗯嗯形態**：依「布里斯托大便分類法」分 7 型，可加「黏馬桶、很費力」等標籤，一天可記多次
- **飲食**：早餐、午餐、晚餐、點心、宵夜；可搜尋 160 多種臺灣常見食物，會自動歸到「辣、油炸、乳製品、咖啡因…」等 15 個大類，也能自己新增食物
- **睡眠、心情、喝水**：睡眠時數與品質、5 種心情表情加細節標籤、喝水杯數
- **日曆**：每天用顏色標出嗯嗯狀況，點日期看當天紀錄
- **分析**：比較「有某個因素的日子」和「其他日子」的不舒服比例，用 Fisher 精確檢定過濾掉比較像巧合的結果，列出可能的關聯（例如吃辣隔天容易拉肚子）。嗯嗯分類採 Rome 標準：第 1–2 型偏便祕、第 3–5 型正常、第 6–7 型偏腹瀉
- **自訂貼圖**：圖示可以換成手機裡的圖片，只存在自己的瀏覽器
- **備份**：匯出／匯入 JSON 備份檔

## 隱私

所有紀錄只存在使用者自己的瀏覽器（localStorage），不會上傳到任何伺服器。換手機或清除瀏覽器資料前，請先到「設定」匯出備份。

## 使用方式

用手機瀏覽器打開網址，選「加入主畫面」，就能像一般 App 一樣使用，離線也能開。

## 開啟 GitHub Pages

Settings → Pages → Build and deployment → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。一兩分鐘後網址會是：

`https://roysph1013.github.io/poo_diary/`
